Atlas Lake

A private tool for storing and querying a large Parquet dataset.

What it is

Atlas Lake is a personal, single-user utility. It keeps a large read-only dataset in cloud storage and runs analytical queries against it. It is not a product, has no sign-ups, and is used by its author only.

Why it asks for Google Drive access

One part of the dataset is stored in a single folder of the operator's own Google Drive. The application needs to upload files to that folder and read them back. That is the only reason it requests Drive access, and the only thing it does with it.
